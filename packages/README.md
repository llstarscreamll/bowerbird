# Shared packages

Language-specific libraries used by more than one Canopy product.

| Directory     | Ecosystem                          |
| ------------- | ---------------------------------- |
| `typescript/` | Angular / TypeScript (`@canopy/*`) |
| `swift/`      | Swift packages (iOS)               |
| `kotlin/`     | Gradle builds (Android)            |

Product apps live under `apps/<product>/`, not here.
